# Урок "Имена переменных"

Часть примеров пришлось придумать, чтобы долго не искать.

## 6.1. Разберите свой код, и сделайте пять примеров, где можно более наглядно учесть в именах переменных уровни абстракции.
1. В интернет-магазине функция используется при расчёте стоимости позиции в корзине.
def multiply_price_by_count(price, count):
    return price * count

Новое имя функции: calculate_item_total

2. В сервисе хранения файлов функция вызывается, когда пользователь удаляет документ из своей папки.
def remove_element_from_array(files, file):
    files.remove(file)

Новое имя функции: remove_file_from_folder

3. В системе управления задачами функция вызывается, когда разработчик завершает работу над задачей.
def move_item_between_lists(item, source, destination):
    source.remove(item)
    destination.append(item)

Новое имя функции: finish_task

4. В сервисе бронирования гостиниц результат используется при расчёте времени проживания гостя.
def count_days(start_date, end_date):
    return (end_date - start_date).days

Новое имя функции: calculate_stay_days

5. В системе для сдачи экзаменов функция определяет результат сдачи экзамена студентом.
def compare_with_threshold(value, threshold):
    return value >= threshold

Новое имя функции: is_exam_passed

## 6.4. Найдите пять имён переменных в своём коде, длины которых не укладываются в 8-20 символов, и исправьте, чтобы они укладывались в данный диапазон.
1. getCurrentModuleDirectoryPath (29 символов) лучше сократить до getDirectoryPath, поместив функцию в класс Module.
2. isOldMetrikaCounterInited (22 символа) лучше сократить до isOldCounterInited (18 символов), так как фукнция лежит в модуле metrika и вне его не используется.
3. successfullyProcessedTransactions (33 символа) можно сократить до successTransactions (19 символов)
