4. К пункту 2.Представление намерений
```php
// Сначала сохраняем заказ, а уведомление отправляем только после commit,
// чтобы пользователь не получил письмо о заказе, который затем откатится.
DB::transaction(function () use ($order) {
    $order->save();

    DB::afterCommit(function () use ($order) {
        Mail::to($order->email)->send(new OrderCreated($order));
    });
});
```
