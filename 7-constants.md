# Константы

## Внесите 12 правок в свой код, в которых улучшите работу с константами, и напишите по каждой, что конкретно вы улучшили.
1. `METRIKA_API_URL = 'https://mc.yandex.ru/collect';`
Вынес в константу URL для обращения по API к системе аналитики.
2. `MIN_TO_DEADLINE = 30; SEC_IN_MIN = 60;`
Вынес в константы дедлайн по предложению, ограниченному по времени и количество секунд в минуте для пересчёта.
3. `SLEEP_INTERVAL_MS = 500;`
В парсере завёл константу с задержкой между запросами.
4. `ERRORS_LOG = 'data/errors.txt';`
В скрипте указал, куда логировать ошибки.
5. `VALID_STATUS_CODE = 200;`
В скрипете для проверки ссылок в рекламном кабинете явно указал, какой код ответа сервера считать валидным.
6. `BASE_COUNTRY_CODE = '+7'; BASE_MASK = ' (___) ___-__-__';`
В модуле валидации поля номера телефона задал код РФ и маску номера телефона для проверки.
7. `SUBJECT = 'Заявка с сайта';`
В модуле отправки заявок на почту указал тему письма (проект маленький, поэтому вариантов писем и способов отправки сообщения не предполагается).
8. Задал группировку констант через объекты в скрипте, который при достижении кол-ва просмотренных на сайте страниц и определённого времени отправляет конверсию в систему аналитики.

9. `PAGE_DEPTH_KEY = 'pageDepth';`
Придумал ключ для localStorage, в котором будет храниться кол-во просмотренных страниц.
10. `HASH_MULTIPLIER = 17`
Для константы, используемой в функции хэширования.
11. `OFFICE_COORDINATES = [30.31095, 59.937086];`
Координаты офиса для Яндекс.Карты.
