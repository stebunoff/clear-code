# Урок: Время связывания переменных

1. Связывание при написании кода в сервисе для работы с аналитикой.
Изменение значений не предполагается -> гибкость не нужна -> можно задать значения константам максимально близко к месту применения, что улучшит читаемость.

```php
class AnalyticsService implements AnalyticsServiceContract
{
    private const METRIKA_COUNTER_ID = 100623435;
    private const URL = 'https://mc.yandex.ru/collect';
    private const BRAND_NAME = 'AdBulls';

    // код класса
}
```

2. В php нет этапа компиляции, поэтому использую максимально близкое к нему связывание на этапе конфигурации приложения.
Команда `php artisan config:cache` собирает конфиги в один закэшированный файл.
Разные значения `APP_URL` из окружения мне требуются только при запуске приложения в dev и prod, поэтому в HTML шаблоне прописано:
```php
<a href="{{ config('app.url') }}">
```

3. Самый частый случай, когда связывание мне требуется при выполнении программы - это при получении текущего времени (например, для временных меток).
```php
$currentTime = now();
```
